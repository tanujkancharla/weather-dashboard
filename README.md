# 🌤️ Weather Dashboard

A responsive weather application that displays real-time weather information for cities worldwide using the OpenWeather API.

## 🚀 Features

- Search weather by city
- Real-time temperature, condition, humidity, and wind speed
- Dynamic weather backgrounds and icons
- Responsive design for desktop and mobile
- Error handling for invalid cities
- Enter key support and loading state

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- OpenWeather API

## ⚙️ Setup

1. Clone the repository.
2. Add your OpenWeather API key to `script.js`.
3. Open `index.html` in your browser.
